> Sistema simples de **controle de estoque**, desenvolvido em linguagem **C**, com funcionalidades básicas para gerenciamento de produtos via terminal.

---

## 📌 Visão Geral

Este projeto foi desenvolvido com foco educacional, para praticar conceitos de programação em C como estruturas, arquivos, menus interativos e manipulação de dados.

🔧 **Tecnologias utilizadas**:

- ✅ Linguagem C
- ✅ Interface via terminal
- ✅ Leitura e escrita em arquivos `.txt`
- ✅ Organização por funções e modularidade básica

---

## ✨ Funcionalidades

- 🔍 Consultar produtos cadastrados  
- ➕ Adicionar novos produtos  
- 📝 Editar dados de um produto  
- ❌ Remover produto do estoque  
- 📦 Verificar quantidade em estoque  

---

## 🚀 Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/joaohgoncalves/Controle-Estoque-C.git
cd Controle-Estoque-C
```

2. Compile o projeto:
```bash
gcc main.c estoque.c -o estoque
```

3. Execute o programa:
```bash
./estoque
```

Certifique-se de ter o gcc instalado no seu sistema.
